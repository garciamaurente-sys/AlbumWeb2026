# Álbum Mundial 2026 🏆

Este es mi proyecto personal para llevar el registro de figuritas del Mundial 2026. 

## Características
- **Seguimiento local:** Guarda tu progreso usando `localStorage`.
- **Diseño Responsive:** Adaptado para usarlo como App en el celular.
- **Secciones especiales:** Incluye Copa del Mundo y colección de Coca-Cola.

## Cómo usarlo
1. Visita la web: (proximamente el link)
2. Haz clic en las figuritas para marcar que las tienes.
3. ¡El progreso se guarda automáticamente en tu navegador!

## Tecnología
- HTML5, CSS3 y JavaScript puro.
